# Portfolio

A personal portfolio that presents real project work to prospective employers.

## Language

**Project**:
A real piece of the portfolio owner's work, whether completed or still in progress.
Planned capabilities are distinct from capabilities that work today.

**In progress**:
A project status indicating that work is ongoing and the project is unfinished.
Its presentation describes the progress that actually exists.
_Avoid_: Coming soon (when referring to work already in progress)

**SPL ERP**:
Oscar's running business application for SPL, covering clients, finances, events, and planning through desktop and web versions.

**Obsidian second brain**:
Oscar's personal knowledge system being built in Obsidian.

**Smart-building RAG architecture study**:
Oscar's research and architecture recommendation for a retrieval-augmented generation system at an unnamed smart-building technology company.
_Avoid_: Jev company, production RAG system (unless deployment is confirmed)
